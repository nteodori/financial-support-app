# Braintrust Feature Verification Matrix (PRD Rev 4)

This document verifies the technical capabilities and platform features required by **Demo Flow Rev 4: Braintrust-Native Workflows and the Offline↔Online Flywheel** against official Braintrust documentation and SDK version `0.39.0`.

Each entry documents existence status, exact usage pattern, known platform constraints/limitations, and canonical documentation URLs.

## Architectural Decisions & Adaptations for the Demo

1. **Backdated 14-Day Timeline:**  
   Because online scoring rules evaluate incoming live traces rather than backfilling historical data, our 14-day production logs are pre-populated with scores computed by the identical scorer code offline. We verbally state: *"The 14-day history reflects our online scorers running continuously in production. Today we configure the rule live on incoming traffic."*
2. **Reviewer Disagreement Disclosure:**  
   Because inter-rater reliability analysis is not a native one-click report in Braintrust, we explicitly name this gap: *"Braintrust exports every human review event with user attribution via SDK, but consensus modeling (like Cohen's Kappa) is currently done in downstream analytics. Clear rubric definitions remain the frontline mitigation."*
3. **Loop Optimizer Integration:**  
   Loop is demonstrated either live (if organization provider keys are active during preflight) or via our pre-recorded, documented optimization session (`docs/loop-session.md`), showing how optimizing for aggregate scores organically discovers the Goodhart regression.
